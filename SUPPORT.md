# Getting help

- **How do I…?** Read the [FAQ](https://github.com/hex-dump/perihub#faq) and the
  [known limitations](https://github.com/hex-dump/perihub#known-limitations), then ask in
  [Discussions → Q&A](https://github.com/hex-dump/perihub/discussions/categories/q-a).
- **My device is not found.** Check that it is in the [device list](docs/devices.md), that the maker's
  app is closed, and on Linux that the udev rule is installed ([README](https://github.com/hex-dump/perihub#usb-permissions)).
  Then a [device request](https://github.com/hex-dump/perihub/issues/new?template=device_request.yml) or a bug report.
- **Something is broken.** A [bug report](https://github.com/hex-dump/perihub/issues/new?template=bug_report.yml).
- **An idea.** [Discussions → Ideas](https://github.com/hex-dump/perihub/discussions/categories/ideas).
- **A security issue.** Privately, as described in [SECURITY.md](SECURITY.md).

PeriHub is maintained by one person in their spare time: answers can take a few days.
