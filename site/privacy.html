Privacy policy

Last updated: 6 November 2026

In short: no cookies, no analytics, no tracking, no telemetry, no account. The website is a static page and the PeriHub app works offline. Neither collects personal data for the maintainer, who never sees who visits the site or uses the app.

This policy covers the website at hex-dump.github.io/perihub and the PeriHub app. It is written to meet the EU General Data Protection Regulation (GDPR, Regulation (EU) 2016/679) and the Italian Personal Data Protection Code (Legislative Decree 196/2003, as amended by Legislative Decree 101/2018).

1. Who is responsible

PeriHub is a free, non-commercial, open-source project maintained by a private individual, hex-dump, based in Italy. It is not a company and does not sell anything. Contact: perihub.app@outlook.com (more in Contact).

2. The website

2.1. What the website does not do

  • It sets no cookies and stores nothing in your browser (no local storage either), so there is no cookie banner.
  • It uses no analytics, trackers, advertising or social media plugins.
  • It loads nothing from other websites: no external fonts, scripts or content delivery networks. All files come from GitHub Pages.
  • It has no forms and asks you for nothing.

The page runs one small script, which you can read in the repository. It reads your browser's user agent to show the download for your system, and copies the page link when you press Copy link. Both happen only in your browser: nothing is sent or saved.

2.2. Hosting: GitHub Pages

The website is hosted by GitHub Pages, a service of GitHub, Inc. (United States), part of Microsoft. As with any web server, your browser sends GitHub technical data such as your IP address and user agent when it loads the page. GitHub states that it may log visitors' IP addresses to keep its service secure and to comply with the law, and it handles this data as an independent controller, under the GitHub General Privacy Statement, which also explains its transfers of data outside the EU. The maintainer has no access to these logs and gets no visitor statistics.

2.3. Downloads

The download buttons point to the files of the latest release on GitHub. Downloading a file is a request to GitHub, as above. The maintainer can only see the total number of downloads of each file, as GitHub shows it to every project, with nothing that identifies who downloaded it.

2.4. Links to other websites

The website links to GitHub (repository, issues, discussions), to Buy Me a Coffee and to a community-maintained Scoop bucket. Those websites have their own privacy policies, which apply once you open them.

3. The PeriHub app

3.1. Data that stays on your PC

PeriHub keeps your settings, saved lightings, app profiles, macros, the backups it makes before writing to a device, and a log file (under 1 MB, which records devices connecting, errors and updates, never your key presses or the apps you use) on your PC only. None of it is sent anywhere. You can delete it at any time, by removing these folders:

  • Linux: ~/.config/perihub/, ~/.local/state/perihub/ and ~/.local/share/io.github.hexdump.perihub/
  • Windows: %APPDATA%\perihub\ and %LOCALAPPDATA%\io.github.hexdump.perihub\

3.2. Key presses and apps in focus

Reactive lighting and software macros read key presses, and app profiles read which app is in focus (its executable name or window class, never window titles or contents). This happens only on your PC, only while you use those features, and nothing of it is stored, logged or sent. The Safety section of the README explains exactly what is read and when.

3.3. The only automatic connection: update checks on Windows

On Windows, when PeriHub starts and then once a day, it asks GitHub for a small file describing the latest release. Like any request, it shows GitHub your IP address. No identifier, setting or device information is sent, and the maintainer receives nothing. You can turn it off in Settings → Updates. When it finds a new version it downloads it from GitHub right away, so that the update starts at once, but it installs it only when you click Update and restart. On Linux, and on Windows when PeriHub was installed with Scoop, the app makes no connections at all.

3.4. Things that happen only when you ask

  • Test reports and bug reports. Open test form opens a GitHub issue form in your browser, filled in with your mouse model and what PeriHub read from it. Nothing is sent until you submit it yourself. Issues and discussions on GitHub are public and governed by GitHub's privacy statement, so do not include personal data you do not want to publish.
  • Macros that open a website start your browser, which connects on its own.

4. Donations

Donations go through Buy Me a Coffee, which handles payments with its own partners under its privacy policy. The maintainer receives only what Buy Me a Coffee passes on to creators, such as the name and message you choose to leave, and uses it only to see and thank supporters. It is not shared with anyone. Donations are optional and unlock nothing.

5. Your rights

Under the GDPR you have the right to access, correct and delete your personal data, to restrict or object to its processing, and to data portability. Since the maintainer collects no personal data through the website or the app, there is normally nothing to access or delete. For data held by GitHub or Buy Me a Coffee, they are the ones who can act on your request, and their policies explain how.

You also have the right to lodge a complaint with a supervisory authority: in Italy, the Garante per la protezione dei dati personali, or the authority of the EU country where you live or work.

6. Children

PeriHub is not aimed at children and, since it collects no personal data, collects none from children either.

7. Changes to this policy

If PeriHub or the website changes how it handles data, this page will be updated first, with a new date at the top. Every change is visible in the history of this file.

8. Contact

For questions about this policy or your data, write to perihub.app@outlook.com. You can also open a discussion on GitHub Discussions, which is public. Security issues go through GitHub's private report form, as explained in SECURITY.md.
