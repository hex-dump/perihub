A Razer Synapse alternative for Windows and Linux, and where it stands

PeriHub recognizes 76 Razer mice and 69 Razer keyboards. None has been tried on real hardware yet, so every one is experimental or read-only. This page says what that means, and how a test report changes it.

The Windows installer is not code-signed yet. If SmartScreen blocks it, click More info, then Run anyway. Quit the maker's app and turn off its autostart before you open PeriHub: two apps talking to the same device get in each other's way.

The problem

One app per brand

Razer, Logitech, Corsair and SteelSeries each want their own program for DPI, polling rate and lights. PeriHub tries to be one open-source app for all of them. For Razer it is the youngest part of that effort, so it is careful.

Built from public documentation

Razer support comes from facts in OpenRazer, with no code copied, not from tests on a real device. That is why the label stays honest: nobody has confirmed any Razer model yet.

What works, at your own risk

Mice (76)

Read on their USB cable, with the battery on 28 that have one. DPI, polling rate (up to 8000 Hz on those that go that high) and the brightness of the lights can be saved to the mouse. The Viper V3 Pro and Pro SE also work behind their own dongle.

One colour

On 27 mice one colour can be sent without saving it, under a warning that it cannot be checked or undone. Lighting effects are never stored, because the mouse cannot report them back.

Keyboards (69)

Read only, on Windows: firmware, layout, backlight brightness, game mode and battery. The BlackWidow V4 Mini HyperSpeed is experimental (brightness, game mode, macro light, effects and one colour) and is the only Razer keyboard PeriHub opens on Linux for now.

Safety net

Saving asks you to tick a No warranty box first. Each save is backed up, read back and undone after 15 seconds unless you keep it.

Receivers and docks are left out, apart from the dongles of those two mice, because some can be shared with a keyboard. Use the USB cable.

Help confirm a Razer model

  1. Download PeriHub above, install it and quit Razer Synapse.
  2. Connect your mouse or keyboard and open Test my device in the sidebar.
  3. Press Open the form and send the report (a free GitHub account is needed). It only reads the device. One report moves the model up for everyone: see Wanted: testers.

Questions

Does PeriHub fully support any Razer device?

Not yet. Razer devices are experimental or read-only until someone with one sends a test report and it is confirmed.

Can I keep Razer Synapse running?

Quit it and turn off its autostart: two programs talking to the same device get in each other's way.

Will it change my lighting effect?

PeriHub never stores a Razer lighting effect, since it cannot read one back. On 27 mice it can show one colour without saving it.

I own a Razer device. How do I help?

Install PeriHub, open Test my device and send the report. It only reads your device, and one report counts for everyone with that model.
