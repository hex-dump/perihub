What it does

Keyboard lighting

8 zones on the Apex 3 TKL: static colors, gradient, breathing, color cycle, wave, reactive (the zone of each key you press lights up) and the built-in rainbow.

Key remapping

Change any key, also on the layer you get while holding the SteelSeries key. Saved in the keyboard, so it works without PeriHub.

Mouse profiles

5 onboard profiles on the G502 HERO, with DPI levels from 100 to 25600, polling rate, the 11 buttons, G-Shift and lighting. All saved in the mouse.

Macros

Record macros into the mouse memory, so they work on any PC. Software macros can also repeat, type text, or open a website or a program.

App profiles

Switch lighting and mouse profile when a game is in focus, and switch back when you leave it. On Windows and on Hyprland.

Small and quiet

A %%EXE_SIZE%% installer for Windows. Closed, it waits in the tray with about 2 MB of memory (measured on version 0.4.0). No background services.

The installer is not code-signed yet. Your browser may say the file is not commonly downloaded: choose Keep. If Windows SmartScreen blocks it, click More info → Run anyway.

Before you start PeriHub, quit SteelSeries GG and Logitech G HUB and turn off their autostart: two apps talking to the same device get in each other's way.

No drivers needed. PeriHub tells you when a new version is out and updates with one click. With Scoop: community bucket.

  • Debian, Ubuntu (.deb) %%DEB_SIZE%%

  • AppImage, any distribution %%APPIMAGE_SIZE%%

Pick the .deb or the .rpm if your distribution uses them: they are much smaller, because they use your system's web engine, and they set up USB access by themselves. The AppImage works everywhere and brings its own engine, which makes it larger.

With the AppImage, see USB permissions. On Arch and CachyOS you can build the package from the repository.

Safe by design

  • No firmware changes. PeriHub only writes the settings the official apps write too, with commands verified one by one.
  • Checked writes and backups. Everything written to a device is read back and compared, and the previous state is saved first.
  • Your data stays on your PC. PeriHub works offline. On Windows it only asks GitHub for new versions, and you can turn that off.
  • Open source. The code is on GitHub under the MIT license. Details in the README.
