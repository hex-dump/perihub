About

Why I made this

I'm a computer science student. My desk has a SteelSeries Apex 3 TKL and a Logitech G502 HERO, which meant two apps from two companies, both heavy, just to set some colors and a few buttons.

Then I moved my gaming PC to Linux, and neither app exists there. So I wrote one app for both. It does a few things and tries to do them well: lights, key remapping, DPI, macros, and a profile that switches when a game opens.

I make it with the help of AI, and I review it and try it on my own keyboard and mouse. Support for other devices comes from people who own them and send a test report.

hex-dump

Not there yet

  • Only four devices are tested on real hardware: G502 HERO, G502 X Wireless, G300 and Apex 3 TKL. The other 200+ are experimental or read-only until someone with one sends a report.
  • Saving a Logitech mouse through its LIGHTSPEED receiver is experimental: one mouse has tried it so far.
  • Corsair devices are only read, plus one color until you close PeriHub.
  • No macOS.
  • The Windows installer is not code-signed yet, so SmartScreen warns you.
  • It can't share a device with the official app: quit G HUB, GG, iCUE or Synapse first.
  • Profiles that follow the game in focus work on Windows, and on Linux on Hyprland, KDE Plasma and GNOME, not on other Linux desktops yet.

Features

What it does

Keyboard lighting

Static colors for each zone, gradient, breathing, color cycle, wave, reactive (the zone of each key you press lights up) and the keyboard's built-in effects.

Key remapping

Change any key, also on the layer you get while holding the SteelSeries key. Saved in the keyboard, so it works without PeriHub.

Mouse profiles

Onboard profiles with DPI levels, polling rate, every button, G-Shift and lighting. All saved in the mouse.

Macros

Record macros into the mouse memory, so they work on any PC. Software macros can also repeat, type text, or open a website or a program.

App profiles

Switch lighting and mouse profile when a game is in focus, and switch back when you leave it. On Windows, and on Linux on Hyprland, KDE Plasma and GNOME.

Light on your PC

A %%EXE_SIZE%% installer for Windows. With the window closed it sits in the tray using about 4 MB of memory and under 1% of one CPU core (version 0.8.2 on Windows 11). No background services.

Which Logitech G mice are supported?

The G502 HERO and the G502 X Wireless are supported whatever their firmware. For the other 28 Logitech G mice with onboard memory, what counts is the format of the memory the mouse reports, not the model. PeriHub reads it every time the mouse is plugged in, and the mouse page shows the level.

Level by memory format and sector size
255-byte sectors256-byte sectors
Profile format 2 Experimental Supportedas on the G502 HERO
Profile format 3 Supportedas on the G502 X Wireless Experimental
Any other format Read-only

Experimental saves need the No warranty box, and each one is undone after 15 seconds unless you keep it. Through a LIGHTSPEED receiver, a supported memory is saved as an experimental feature, as G HUB does; otherwise PeriHub only reads. What libratbag found so far: the G900 uses format 3, the G203 format 4 and the G502 X PLUS format 5, so the last two are read-only.

Is your device on the list? Help make it supported

  1. Install PeriHub and quit the maker's app (G HUB, GG, iCUE, Synapse…).
  2. Connect the device with its USB cable.
  3. Open its page in PeriHub and press Open test form. It opens a report on GitHub with what PeriHub read already filled in.
  4. Check that it matches your device, and send it. You need a free GitHub account.

It takes a few minutes and it is safe: sending a report only reads the device. Wanted: testers lists every model that needs one.

Send a test report

Not on the list?

In PeriHub, Settings → Devices → Send a report lists the devices it does not know and opens a device request already filled in. You can also open a device request on GitHub.

Safety

What it writes, and what it doesn't

  • No firmware changes. PeriHub only writes the settings the official apps write too, with commands verified one by one.
  • Checked writes and backups. Everything written to a device is read back and compared, and the previous state is saved first.
  • Your data stays on your PC. PeriHub works offline. On Windows it only asks GitHub for new versions, and you can turn that off.
  • Open source. The code is on GitHub under the MIT license. Details in the README.
