What it does

Keyboard lighting

Static colors for each zone, gradient, breathing, color cycle, wave, reactive (the zone of each key you press lights up) and the keyboard's built-in effects.

Key remapping

Change any key, also on the layer you get while holding the SteelSeries key. Saved in the keyboard, so it works without PeriHub.

Mouse profiles

Onboard profiles with DPI levels, polling rate, every button, G-Shift and lighting. All saved in the mouse.

Macros

Record macros into the mouse memory, so they work on any PC. Software macros can also repeat, type text, or open a website or a program.

App profiles

Switch lighting and mouse profile when a game is in focus, and switch back when you leave it. On Windows and on Hyprland.

Small and quiet

A %%EXE_SIZE%% installer for Windows. Closed, it waits in the tray with about 3 MB of memory (measured on version 0.5.5). No background services.

Which Logitech G mice are supported?

The G502 HERO and the G502 X Wireless are supported whatever their firmware. For the other 26 Logitech G mice with onboard memory, what counts is the format of the memory the mouse reports, not the model. PeriHub reads it every time the mouse is plugged in, and the mouse page shows the level.

255-byte sectors256-byte sectors
Profile format 2Format 2, 255-byte sectorsExperimentalFormat 2, 256-byte sectorsSupportedas on the G502 HERO
Profile format 3Format 3, 255-byte sectorsSupportedas on the G502 X WirelessFormat 3, 256-byte sectorsExperimental
Any otherAny other formatRead-only

Experimental saves need the USB cable and the No warranty box, and each one is undone after 15 seconds unless you keep it. Through a LIGHTSPEED receiver nothing is saved: with a supported memory PeriHub switches the profile and DPI level, otherwise it only reads. What libratbag found so far: the G900 uses format 3, the G203 format 4 and the G502 X PLUS format 5, so the last two are read-only.

Is your device on the list? Help make it supported

  1. Install PeriHub and quit the maker's app (G HUB, GG, iCUE, Synapse…).
  2. Connect the device with its USB cable.
  3. Open its page in PeriHub and press Open test form. It opens a report on GitHub with what PeriHub read already filled in.
  4. Check that it matches your device, and send it. You need a free GitHub account.

It takes a few minutes and it is safe: sending a report only reads the device.

Send a test report

Not on the list? In PeriHub, Settings → Devices → Send a report lists the devices it does not know and opens a device request already filled in. You can also open a device request on GitHub.

Pick the .deb or the .rpm if your distribution uses them: they are much smaller, because they use your system's web engine, and they set up USB access by themselves. The AppImage works everywhere and brings its own engine, which makes it larger.

With the AppImage or the Flatpak, see USB permissions. The Flatpak does not update by itself: how to install it. On Arch and CachyOS you can build the package from the repository.

Safe by design

  • No firmware changes. PeriHub only writes the settings the official apps write too, with commands verified one by one.
  • Checked writes and backups. Everything written to a device is read back and compared, and the previous state is saved first.
  • Your data stays on your PC. PeriHub works offline. On Windows it only asks GitHub for new versions, and you can turn that off.
  • Open source. The code is on GitHub under the MIT license. Details in the README.
