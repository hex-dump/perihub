What it does

Keyboard lighting

Static colors for each zone, gradient, breathing, color cycle, wave, reactive (the zone of each key you press lights up) and the keyboard's built-in effects.

Key remapping

Change any key, also on the layer you get while holding the SteelSeries key. Saved in the keyboard, so it works without PeriHub.

Mouse profiles

Onboard profiles with DPI levels, polling rate, every button, G-Shift and lighting. All saved in the mouse.

Macros

Record macros into the mouse memory, so they work on any PC. Software macros can also repeat, type text, or open a website or a program.

App profiles

Switch lighting and mouse profile when a game is in focus, and switch back when you leave it. On Windows and on Hyprland.

Small and quiet

A %%EXE_SIZE%% installer for Windows. Closed, it waits in the tray with about 3 MB of memory (measured on version 0.5.5). No background services.

Experimental Recognized, not all tested yet

28 more Logitech G mice are recognized: 25 with a USB cable, and 14 wireless models through their LIGHTSPEED receiver. PeriHub shows their profiles, DPI, buttons, lighting and battery. From 0.6.7 what it changes depends on the format of the memory each mouse reports, not on the model: a format already tested on another mouse makes the mouse supported; a format PeriHub can write but nobody has tried yet can be edited at your own risk with the USB cable, after a No warranty box, and every save is backed up and undone after 15 seconds unless you keep it; any other format is read-only. Nothing is saved through a receiver.

Is your mouse on the list? Help make it fully supported

  1. Install PeriHub and quit Logitech G HUB.
  2. Connect the mouse with its USB cable, or turn it on with its LIGHTSPEED receiver plugged in.
  3. Open PeriHub, go to the mouse page and press Open test form. It opens the report on GitHub with what PeriHub read already filled in.
  4. Check that profiles, DPI and buttons match your mouse, and send it. You need a free GitHub account.

It takes a few minutes and it is safe: sending a report only reads the mouse.

Send a test report

Another device? Open a device request: new devices are added one at a time, after a test on real hardware. Other brands, like Corsair or Razer, can be requested too.

PeriHub has applied to SignPath Foundation for free code signing for open source projects. See the code signing policy.

Before you start PeriHub, quit SteelSeries GG and Logitech G HUB and turn off their autostart: two apps talking to the same device get in each other's way.

No drivers needed. PeriHub tells you when a new version is out and updates with one click. With Scoop: community bucket.

Linux

  • Debian, Ubuntu (.deb) %%DEB_SIZE%%
  • Fedora, openSUSE (.rpm) %%RPM_SIZE%%
  • AppImage, any distribution %%APPIMAGE_SIZE%%

Pick the .deb or the .rpm if your distribution uses them: they are much smaller, because they use your system's web engine, and they set up USB access by themselves. The AppImage works everywhere and brings its own engine, which makes it larger.

With the AppImage, see USB permissions. On Arch and CachyOS you can build the package from the repository.

Safe by design

  • No firmware changes. PeriHub only writes the settings the official apps write too, with commands verified one by one.
  • Checked writes and backups. Everything written to a device is read back and compared, and the previous state is saved first.
  • Your data stays on your PC. PeriHub works offline. On Windows it only asks GitHub for new versions, and you can turn that off.
  • Open source. The code is on GitHub under the MIT license. Details in the README.
