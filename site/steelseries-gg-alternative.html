A SteelSeries GG alternative for Windows and Linux

PeriHub fully supports the SteelSeries Apex 3 TKL: lighting, brightness, key remapping and macros, tested on real hardware. Other SteelSeries keyboards and mice are recognized, with the limits below.

The Windows installer is not code-signed yet. If SmartScreen blocks it, click More info, then Run anyway. Quit the maker's app and turn off its autostart before you open PeriHub: two apps talking to the same device get in each other's way.

The problem

A heavy app for a few settings

To light a keyboard or move a key you install SteelSeries GG. Neither GG nor Logitech's G HUB exists on Linux, and PeriHub started to fix that for one desk with an Apex 3 TKL and a G502 HERO.

What PeriHub does instead

Key remapping is saved in the keyboard, so it works without PeriHub. Lighting on the Apex 3 TKL is not stored by the keyboard, with GG too, so PeriHub reapplies it as soon as it sees the keyboard and waits in the tray with the window closed.

Apex 3 TKL: what works

Lighting

8 zones: static, gradient, breathing, colour cycle, wave, reactive (the zone of each key you press lights up), built-in rainbow, or off.

Key remapping

Any key, on the normal layer and on the layer you get while holding the SteelSeries key, shown in the layout PeriHub detects: ANSI, ISO, JIS or ABNT2.

Brightness and macros

Brightness from 0 to 100% in 17 steps, in sync with SteelSeries + F11/F12. A key such as SteelSeries + 1 can start a software macro run by PeriHub.

On Linux, reactive lighting and macro keys need a second udev rule. With it installed, every program running under your user account can read what you type on that keyboard, so install it only if you want those features.

Other SteelSeries devices

Supported: tested on real hardware

  • Apex 3 TKL
  • Rival 700 / Rival 710

The Apex 3 TKL is tested on Windows and on Linux; a user confirmed the Rival 700 / Rival 710 on Windows.

Experimental: nobody has tried them yet

  • Apex Pro
  • Apex 7
  • Apex 7 TKL
  • Apex 5
  • Aerox 3
  • Prime
  • Rival 3
  • Sensei TEN

The Apex Pro, 7, 7 TKL and 5 can have their brightness changed, plus one colour and a display picture sent without saving. The other 32 SteelSeries mice (Rival, Sensei, Aerox, Prime, Kana, Kinzu) cannot report their settings, so DPI, polling rate and colours are sent one at a time and never saved. The Apex 3 is recognized but PeriHub sends it nothing yet.

Not there yet

  • GameSense is not available yet. SteelSeries Sonar and Moments are out of scope.
  • Key actuation points (OmniPoint), key remapping, macros and onboard profiles of the Apex Pro, 7, 7 TKL and 5 have no public source yet.
  • No macOS, and the Windows installer is not code-signed yet.

Questions

Which SteelSeries devices are fully supported?

The Apex 3 TKL keyboard and the Rival 700 / Rival 710 mouse have been tested on real hardware. The Apex Pro, 7, 7 TKL, 5 and the other 32 mice are experimental, and the Apex 3 is recognized only.

Can I keep SteelSeries GG running?

No. Quit it and turn off its autostart: two programs talking to the same device get in each other's way.

Why does my Apex 3 TKL go back to the rainbow when PeriHub is closed?

The Apex 3 TKL does not store colours, with GG too. PeriHub reapplies them as soon as it sees the keyboard, and keeps running in the tray when you close its window.

Does it work on Linux?

Yes, for the Apex 3 TKL. Reactive lighting and macro keys need an optional udev rule that PeriHub offers to install, with a warning about what it allows.
