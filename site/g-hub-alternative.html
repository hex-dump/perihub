A Logitech G HUB alternative for Windows and Linux

PeriHub changes DPI, buttons, lighting and macros on supported Logitech G mice, with no account and no telemetry. Settings are saved in the mouse, so they keep working with PeriHub closed.

The Windows installer is not code-signed yet. If SmartScreen blocks it, click More info, then Run anyway. Quit the maker's app and turn off its autostart before you open PeriHub: two apps talking to the same device get in each other's way.

The problem

G HUB does a lot

G HUB covers many Logitech products. To change a DPI step, remap a button or pick a light colour, that is a big program for a small job. It also takes control of the mouse when it starts and after every wake-up, so the mouse stops using the profiles stored inside it. And there is no G HUB for Linux.

What PeriHub does instead

It writes your settings into the mouse itself, as onboard profiles. Close PeriHub and they still apply, on this PC or any other. The Windows installer is %%EXE_SIZE%%. On a real Windows 11 PC, PeriHub 0.8.2 used about 4 MB of memory while it waited in the tray. No background services, ads or account; MIT license.

What works today

DPI and polling rate

On the G502 HERO: up to 5 DPI levels from 100 to 25600, with a default and a sniper level, previewed live on the mouse. Polling rate of 125, 250, 500 or 1000 Hz.

Buttons and G-Shift

11 buttons plus the G-Shift layer: clicks, keys with modifiers, media keys, DPI and profile functions.

Lighting

Logo and DPI indicator: off, fixed colour, breathing or colour cycle, with a live preview.

Macros

Recorded into the mouse, so they work on any PC. Software macros can also repeat, type text or open a program or website; PeriHub has to be running for those.

App profiles

The mouse profile follows the game in focus. On Windows, and on Linux on Hyprland, KDE Plasma and GNOME.

Which Logitech devices

Experimental means changes are at your own risk, with a warning on screen and a No warranty box before the first save. Each save is backed up and undone after 15 seconds unless you keep it.

Supported: tested on real hardware

  • G502 HERO
  • G502 X Wireless
  • G300

The G502 HERO is tested on Windows and on Linux. Users confirmed the G502 X Wireless (with its cable) and the G300 on their own mice, on Windows; nobody has saved to either on Linux yet.

Depends on the mouse: 28 more G mice

  • G Pro
  • G Pro X Superlight
  • G403
  • G703
  • G903 HERO
  • G305
  • G502 X PLUS

PeriHub reads the memory format each mouse reports. A format already tested on another mouse counts as supported. A format PeriHub can write but nobody has tried is experimental, and the G502 X PLUS uses a newer one that stays read-only.

Experimental: recognized, nobody has tried it yet

  • G600
  • G500s
  • G700s
  • G213 Prodigy keyboard (Windows, lighting)
  • LIGHTSPEED receiver
  • Logi Bolt receiver
  • Unifying receiver

Devices on a Logi Bolt or Unifying receiver (MX Master, MX Anywhere, MX Keys) get a page with battery and DPI; only the DPI of those without onboard memory can be changed. Read-only: G9, G500, G700.

Switching from G HUB

  1. Download PeriHub above and install it.
  2. Quit G HUB and turn off its autostart. PeriHub shows a warning while G HUB runs, and gives the mouse its profiles back once it is closed.
  3. Open PeriHub: your mouse appears in the sidebar. Pick a profile, change DPI, buttons or lighting, then press Save to mouse.

Not there yet

  • G HUB supports many more devices and features. G HUB Lua scripts are out of scope for PeriHub.
  • Only three Logitech mice are tested. Saving through a LIGHTSPEED receiver is experimental, and one mouse has tried it so far.
  • PeriHub does not run on macOS.

Questions

Is PeriHub a full replacement for G HUB?

No. G HUB supports many more devices and features. PeriHub covers fewer Logitech models, says honestly which ones it has tested, and leaves out G HUB Lua scripts.

Can I keep G HUB running?

No. G HUB takes control of the mouse when it starts and after every wake-up, so the mouse stops using its onboard profiles. Quit it and turn off its autostart.

Does it work on Linux?

Yes. There are .deb, .rpm, Flatpak and AppImage files, and an Arch package built from the repository. The .deb and .rpm set up USB access by themselves; the AppImage and Flatpak need one udev rule installed by hand.

Is it safe for my mouse?

PeriHub does not touch firmware and writes only settings that the official apps write too. It backs up the mouse before every write and reads every write back. Experimental features carry no warranty.
