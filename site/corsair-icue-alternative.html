A Corsair iCUE alternative for Windows and Linux: current status

PeriHub recognizes 26 Corsair mice, 23 Corsair keyboards and 6 receivers. No Corsair device has been tried on real hardware yet, so PeriHub reads them and can try one colour. It does not replace iCUE today.

The Windows installer is not code-signed yet. If SmartScreen blocks it, click More info, then Run anyway. Quit the maker's app and turn off its autostart before you open PeriHub: two apps talking to the same device get in each other's way.

What it looks like

PeriHub reads the device and offers one colour for the session, nothing more, until someone confirms it.

The problem

Lights and settings in one app

If you own Corsair gear alongside other brands, you end up with one program per maker. PeriHub aims to cover them all in one small app, but Corsair is still early, and it says so.

Where the protocol comes from

Corsair support is written from the protocol described in ckb-next and OpenLinkHub, in PeriHub's own words with no code copied. It has not been checked on a real Corsair device.

What it does and does not do

Read

PeriHub reads Corsair devices: what they are and what they report. It sends only property reads, apart from the lighting below.

Try one colour

On the device page, Try experimental lighting sends one colour to every LED or key for this session, at your own risk. The device gets its own settings back after 15 seconds unless you keep it, when you quit PeriHub, and as soon as anything fails.

Not offered

DPI, polling rate, buttons and the device's memory. The lighting option is also not offered while iCUE, OpenRGB, ckb-next or OpenLinkHub is running.

  • With more than one device on the same receiver, only the first one is shown.
  • The Slipstream V2 receiver is not recognized.

Help confirm a Corsair model

  1. Download PeriHub above, install it and quit iCUE.
  2. Connect the device and open Test my device in the sidebar.
  3. Press Open the form and send the report. It only reads the device, and one report helps everyone with that model: Wanted: testers.

Questions

Can PeriHub replace iCUE today?

No. For Corsair it reads the device and can try one colour for a session. DPI, buttons and onboard memory are not offered.

Does it work on Linux?

PeriHub runs on Linux and recognizes the Corsair models on both systems, but none has been tried on real hardware yet.

Can I run it next to iCUE, OpenRGB or ckb-next?

The experimental lighting is switched off while iCUE, OpenRGB, ckb-next or OpenLinkHub is running, so two programs do not fight over one device.

How do I get my Corsair model confirmed?

Send a test report from Test my device in PeriHub. It only reads the device.
